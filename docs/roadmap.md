# 📱 Current Development Mode

At the current stage PAYDO.TJ is being developed with an **offline-first UI**.

Firebase, database, payments and production backend will be connected after the corresponding UI and application architecture are ready.

---

# 🏁 Final Goal

PAYDO.TJ should become a unified platform where users can:

- 🛒 Buy and sell products
- 💼 Find and publish jobs
- 🛠️ Offer and find services
- 📢 Publish announcements
- 🗺️ Find stores on a map
- 🚚 Order delivery
- 💬 Communicate through chat
- 🛍️ Create orders
- 💳 Make payments
- 📊 Manage seller accounting
- 🔔 Receive notifications
