# Python Crash Course — китобхонаи омӯзишӣ

Ин ҷузвдон барои илова кардани китоби Python Crash Course ба PAYDO.TJ пешбинӣ шудааст.

## Сохтор
- `assets/python_crash_course.pdf` — нусхаи PDF-и китоб (ҳангоми дастрас шудани файли бинарӣ илова карда мешавад).
- Reader-и Flutter дар `lib/features/python_book/`.
- APK тавассути GitHub Actions сохта мешавад.

## Эзоҳ
PDF-и аслӣ аз ҷониби корбар дар чат бор шудааст. GitHub Contents API барои файлҳои бинарии PDF дар ин пайвастшавӣ дастрас нест. Барои пешгирӣ аз ҷойгир кардани файли қалбакӣ ё холӣ, худи PDF ҳоло илова нашудааст. Файли PDF бояд тавассути Git ё GitHub Releases/Actions artifact ба роҳи `books/python_crash_course/assets/python_crash_course.pdf` бор карда шавад.

Ин директория китоби «Фарҳангшиносӣ»-ро тағйир намедиҳад; ҳар ду китоб метавонанд дар дохили PAYDO.TJ ҳамчун бахшҳои алоҳида бошанд.
